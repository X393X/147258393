# Todaysunny Current Ease

A custom Shopify theme for Todaysunny, assembled on the official Shopify Dawn v15.4.1 foundation.

## Brand direction

- Primary campaign: **Winter Ease**
- Primary products: women’s warm-lined Chelsea boots and commuter ankle boots
- Tagline: **Style Made for Today.**
- Brand promise: **Today’s style, made for real life.**
- Brand colors: Warm Ivory, Soft White, Espresso Brown, Sunlit Gold, Terracotta Rose, and Soft Sage
- Typography: DM Serif Display headings and Manrope commerce text

## Custom experience

- Separate desktop and mobile image/video hero
- Boot-category cards
- Dawn-native featured collection and quick add
- Product-value grid
- Featured-product editorial image/video block
- Optional 9:16 UGC carousel
- Brand statement section
- Product-benefit strip powered by Shopify product metafields
- Todaysunny About page template
- Branded header, footer, product cards, cart drawer, and product page

## Shopify-native systems retained

Dawn’s product forms, variants, search, cart drawer, collection filters, localization, customer account entry, and checkout handoff remain intact.

## Build

The GitHub Actions workflow extracts the source payload, clones official Dawn v15.4.1, applies the Todaysunny brand layer, runs automated tests and Shopify Theme Check, and publishes a verified downloadable artifact.

## Upload

Upload only `todaysunny-current-ease-theme.zip` in Shopify Admin → Online Store → Themes → Add theme → Upload zip file. Keep the theme unpublished until real products, collections, media, policies, rates, payments, mobile views, cart, checkout, and one complete order have been tested.

The theme does not ship with fake reviews or unsupported waterproof, slip-proof, shipping, medical, or guarantee claims.
